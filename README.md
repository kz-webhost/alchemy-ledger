# 연금장부 시세 그래프

연금술 아이템의 공개 경매 시세를 둘러보는 정적 웹 미리보기.

- 품목 검색, 제작품 필터, 24시간 / 7일 / 30일 / 전체 기간
- 경매 최저가, 제작 재료비, 각 재료 가격의 표시 전환
- 경매장 매물 수량, 마우스·터치 가격 조회, 시세 기록 표
- 한국 시각 기준, 마지막 수집 시점을 기준으로 기간 계산

## 공개 데이터 범위

`data.json`은 별도 허용 목록 방식으로 만든 스냅샷이다. 아이템 ID·게임 내 이름·공개 웹 시세의 시각/최저가/전체 매물 수량과 게임 레시피의 재료·수량만 포함한다. 캐릭터, 계정, 개인 거래·구매·판매, 우편, 채팅, 보유 골드·재고, 개인 스캔 시각, 설정, 로컬 경로는 포함하지 않는다. 애드온 원본이나 SavedVariables는 이 저장소에 넣지 않는다. 외부 분석·추적 스크립트와 외부 요청도 없다.

이 웹사이트는 기존에 수집한 공개 경매장 시세의 스냅샷이며, 추가 수집이나 실시간 동기화를 하지 않는다. 게임 레시피는 제작 재료 설명을 위해 제공하며 특정 캐릭터의 습득 여부를 나타내지 않는다.

재료비는 그 시각까지 확인된 재료 경매 최저가를 사용한다. 상점 할인·상점가·경매 수수료는 반영하지 않는다. 기간 평균은 표시 기간 안의 관측 최저가의 산술평균이다. 그래프에는 관측 기록만 표시하며 없는 시간의 가격을 생성하지 않는다.

## 로컬 실행

```sh
python3 -m http.server 8765
```

GitHub Pages는 `main` 브랜치의 루트를 게시한다. HTML의 `noindex,nofollow,noarchive,nosnippet,noimageindex`로 검색엔진에 색인·검색 미리보기 제외를 지시한다. 검색엔진이 이 지시를 읽을 수 있도록 HTML 크롤링은 차단하지 않는다. 프로젝트 경로의 robots.txt는 도메인 루트의 robots.txt를 대체하지 않는다. 사이트와 저장소는 공개이며, 검색 제외는 접근 통제가 아니다.
