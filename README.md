# 연금장부 시세 그래프

연금술 아이템의 공개 경매 시세를 둘러보는 정적 웹 미리보기.

- 최근 개당 예상 이득 내림차순이 기본이며, 수익률·판매가·이름 순으로 변경 가능
- 제작품별 예상 이득과 재료비 대비 수익률, 기본 제작품 필터
- 제조법 학습에 필요한 연금술 숙련도, 명시된 캐릭터 레벨 조건만 표시
- 다른 제작의 재료로 쓰이는 제작품 표시, 사용처별 1회 제작 필요 수량과 시세 이동
- 제작 쿨타임 유무·기본 시간·다른 제조법과의 공유 여부 표시 (완성품 사용 쿨타임과 구분)
- 게임 캐시 기준 제조법 습득·미습득·미확인 필터, 캐릭터 레벨·연금술 숙련도 필터 (필터는 브라우저에 저장)
- 품목 검색, 제작품 필터, 24시간 / 7일 / 30일 / 전체 기간
- 경매 최저가, 제작 재료비, 각 재료 가격의 표시 전환
- 내 구매 ■, 정산 확인 판매 ◆, 등록가 추정 판매 ◇ 표시와 거래 표
- 제작품 그래프에서 재료 거래 함께 보기, 내 거래 품목 필터
- 경매장 매물 수량, 마우스·터치 가격 조회, 시세 기록 표
- 한국 시각 기준, 마지막 수집 시점을 기준으로 기간 계산

## 공개 데이터 범위

`data.json`은 별도 허용 목록 방식으로 만든 스냅샷이다. 아이템 ID·게임 내 이름·공개 웹 시세의 시각/최저가/전체 매물 수량과 게임 레시피의 재료·수량을 포함한다. 사용자가 요청한 구매·판매 기록은 거래 시각, 품목, 개당 가격, 수량, 가격 구분만 별도 허용 목록으로 내보낸다. 캐릭터, 계정, 우편 원문, 채팅, 보유 골드·재고, 개인 스캔 시각, 설정, 로컬 경로는 포함하지 않는다. 애드온 원본이나 SavedVariables는 이 저장소에 넣지 않는다. 외부 분석·추적 스크립트와 외부 요청도 없다.

이 웹사이트는 기존에 수집한 공개 경매장 시세의 스냅샷이며, 추가 수집이나 실시간 동기화를 하지 않는다. 제조법 습득 여부는 별도 `knowledge.json`에서 가져온다. 최근 접속 캐릭터의 아이템별 습득 참·거짓, 게임 저장 시각·확인 시각만 허용하며 캐릭터 이름·GUID·서버·계정은 포함하지 않는다.

재료비는 그 시각까지 확인된 재료 경매 최저가를 사용한다. 상점 할인·상점가는 반영하지 않는다. 예상 이득은 판매가 × 95% − 재료비로 경매 수수료 5%를 반영한다. 수익률은 이득 ÷ 재료비 × 100이다. 여러 개가 제작되는 레시피는 재료비를 결과물 수량으로 나눠 개당 계산한다. 목록 정렬과 상단 이득은 각 품목의 가장 최근 시세를 사용하며, 선택한 그래프 기간에 영향받지 않는다. 최근 매물이 없거나 재료 가격이 부족하면 계산 불가로 표시하고 정렬에서 뒤로 보낸다. 기간 평균은 표시 기간 안의 관측 최저가의 산술평균이다. 그래프에는 관측 기록만 표시하며 없는 시간의 가격을 생성하지 않는다.

구매가는 애드온에 저장된 가격이며, 가격 안내를 놓친 건은 당시 시세가 대신 저장됐을 수 있다. 판매가는 정산 확인과 등록가 추정을 구분한다. 가격이 없는 거래도 표에는 포함하되 그래프 좌표를 만들지 않는다. 시세가 없는 거래 품목도 목록과 거래 표에 표시한다. 아이템 ID를 알 수 없는 품목에는 내부 표시용 키만 부여하며 게임 아이템 ID로 표기하지 않는다.

## 로컬 실행

```sh
python3 -m http.server 8765
```

GitHub Pages는 `main` 브랜치의 루트를 게시한다. HTML의 `noindex,nofollow,noarchive,nosnippet,noimageindex`로 검색엔진에 색인·검색 미리보기 제외를 지시한다. 검색엔진이 이 지시를 읽을 수 있도록 HTML 크롤링은 차단하지 않는다. 프로젝트 경로의 robots.txt는 도메인 루트의 robots.txt를 대체하지 않는다. 사이트와 저장소는 공개이며, 검색 제외는 접근 통제가 아니다.

제조법 습득 여부는 게임에서 캐릭터별로 캐싱하고 `/reload`·로그아웃으로 SavedVariables가 저장되면 로컬 자동 게시기가 변경을 확인해 갱신한다. 웹은 접속 시와 열린 동안 1분마다 확인하고, 연결 실패 시 마지막 정상 브라우저 캐시를 사용한다. 수동 습득 설정은 사용하지 않는다. 데이터 미확인은 미습득으로 추정하지 않는다. 필터는 이 브라우저의 localStorage에만 저장하며 초기화는 게임 습득 기록에 영향을 주지 않는다. 레벨 필터는 학습 조건과 전문기술 단계의 최소 캐릭터 레벨(숙련 75까지 1, 150까지 10, 225까지 20, 그 이상 35)을 함께 고려하고 완성품 사용 레벨은 사용하지 않는다. 확인되지 않은 숙련·레벨 조건은 기본적으로 포함하며 옵션으로 제외할 수 있다. 평판·획득 경로·선행 퀘스트·도구 충족 여부는 필터가 판정하지 않는다. 재료 품목에는 제조법 필터를 적용하지 않는다.

제작 쿨타임은 포에버 제조 주문의 툴팁을 조사한 정적 정보다. 현재 캐릭터의 남은 시간·제작 이력은 공개하거나 계산하지 않는다. 철→금과 미스릴→진은은 각각 독립 1시간, 아케이나이트·군단석은 47시간, 정수 변환 8종은 23시간, 자연의 불꽃은 10분이다. 후자의 11개는 변환 공유 그룹이며, 선택한 제조법의 시간 동안 그룹 전체가 잠긴다. 정제된 오닉시아 비늘은 2시간이며 공유 여부 미확인이다. 쿨타임이 있는 14개 제조법의 1회 이득을 연속 제작 가능한 수익으로 해석하지 않는다.
